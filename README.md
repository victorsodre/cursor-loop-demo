# cursor-loop-demo

A minimal, reproducible Git workflow for demonstrating the loop: branch → bad edit → restore → pull request.

This repository documents a Git workflow by [Victor Sodré](https://github.com/victorsodre). It has no API, build step, or runtime interface.

## Run the demonstration

1. Open this folder in Cursor.
2. Read this README; it is the only file required for the exercise.
3. Create a branch before asking an agent to edit.
4. Review the complete diff, restore an unwanted change, and open a pull request only for the final approved work.

The supporting [briefing](package/BRIEFING.md) and [thread draft](package/THREAD.md) document the intended recording and posting workflow. They are drafts, not publication instructions.
