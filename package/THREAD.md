## Como capturar os 3 prints (Victor)
1. **Diff ruim**: após o agente mexer errado: tela cheia do diff (arquivo errado / hunk fora do pedido / regressão óbvia). Sem blur de path se for teu repo de demo.
2. **Revert limpo**: depois do restore/revert: `git status` limpo ou working tree de volta. Antes|depois na mesma janela se couber.
3. **PR aberto**: tela do PR (título + description curta). Sem número inventado; só depois da sessão real.
Opcional: print da **branch** nova (`git checkout -b …` / status na branch) se o T3 pedir reforço visual.

Checklist rápido: [x] diff ruim  [x] revert limpo  [x] PR aberto  [ ] (opcional) branch
